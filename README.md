# Rock Paper Scissors

A simple, browser-based Rock Paper Scissors game built with JavaScript for The Odin Project.

## Features
- Plays a full 5-round match against the computer using browser prompts.
- Tracks and displays live scores in the console after each round.
- Uses a mathematical modulo formula `(computer - human + 3) % 3` to determine winners instead of long if/else chains.

## How to Play
1. Open the `index.html` file in any web browser.
2. Open your browser's developer tools (F12 or right-click -> Inspect) and go to the **Console** tab to watch the score.
3. Type your choice (`rock`, `paper`, or `scissors`) into the pop-up prompt box.
4. Play all 5 rounds to see the final match winner!
